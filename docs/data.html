10.1 Temporal data

retweets_niwa

The times (POSIXct, UTC) of the 4890 retweets of NIWA’s tweet about a USB stick found in leopard seal scat (the tweet). This is a plain vector of date-times, which needs to be converted to numeric times and sorted before fitting (Section 2.3). Retweets are recorded to the nearest second and some share the same second.

data(retweets_niwa, package = "stelfi")
head(retweets_niwa)

[3] "2019-02-07 06:49:22 UTC" "2019-02-07 06:48:48 UTC"
[5] "2019-02-07 06:47:52 UTC" "2019-02-07 06:47:42 UTC"
ggplot(data.frame(time = retweets_niwa), aes(x = time)) +
    geom_histogram(bins = 50) + ylab("Number of retweets") + xlab("") + theme_bw()

uk_serial

A summary table of 62 UK serial killers (1828–2015) from Murder UK, with the approximate number of murders, the years they were active, and (where known) the month and year of the first murder. The dates are approximate (to the month or year), so a Hawkes model would need the times to be jittered within the recorded month or year (Section 2.1.1), and with only 62 events there is little information to estimate self-excitement.

multi_hawkes

A simulated two stream Hawkes process with \(\mu_1 = \mu_2 = 0.2\), \(\beta_1 = \beta_2 = 0.7\), and \(\boldsymbol{\alpha}\) with diagonal elements 0.5 and off-diagonal elements 0.1 (see Chapter 4). It is a data frame with the sorted event times and the stream of each event, exactly the format needed by fit_mhawkes().

10.2 Spatial and spatiotemporal data

The following datasets are sf objects of type POINT, with the location of each event (longitude and latitude) in the geometry column and other information in the remaining columns. Before fitting a spatial model the locations should be projected (Section 6.1.1). Below, country boundaries for plotting are obtained from the maps package.

sf::sf_use_s2(FALSE)
boundary <- function(region = ".", database = "world") {
    maps::map(database, region, fill = TRUE, plot = FALSE) |>
        sf::st_as_sf() |>
        sf::st_make_valid()
}

sasquatch

972 reported sasquatch (bigfoot) sightings in the contiguous USA, 2000–2005, collated by the Bigfoot Field Researchers Organization (source), with the date and a range of descriptive and weather information. Note that these are reported sightings, so their distribution reflects where people are as well as (possibly) where sasquatch are (Section 6.1.1). Some sightings share the same location.

iraq_terrorism

4208 terrorism events carried out by ISIL in Iraq, 2013–2017, from the Global Terrorism Database. The date is recorded as separate year (iyear), month (imonth) and day (iday) columns, and there is information on each event including the number killed (nkill, missing for some events), the spatial accuracy of the recorded location (specificity), and the (scaled) population density, luminosity and travel time to the nearest city at the event location.

10.3 Simulated data

xyt

A simulated self-exciting spatiotemporal point pattern of 653 events, stored as a stppp object (from the stpp package): the locations are xyt$x and xyt$y, the times are xyt$t (in \([0, 2]\)), and the study region is xyt$window (a spatstat owin, which can be converted to sf using sf::st_as_sf(xyt$window)). Its study region is used in Section 8.2.

data(xyt, package = "stelfi")
ggplot(data.frame(x = xyt$x, y = xyt$y, t = xyt$t), aes(x = x, y = y, size = t)) +
    geom_point(alpha = 0.4) +
    geom_sf(data = sf::st_as_sf(xyt$window), fill = NA, inherit.aes = FALSE) +
    theme_void()

marked

A simulated marked point pattern of 159 events in the square \([0, 3] \times [0, 3]\): a data frame with the locations (x, y) and three marks, m1 (Gaussian), m2 (binary, 0/1) and m3 (gamma). It is used in the examples of fit_mlgcp() (see ?fit_mlgcp); the simulated example in Section 7.2 simulates its own data instead, so that the true parameter values are known.

horse_mesh and horse_sf

An example mesh (created using fmesher::fm_mesh_2d()) and the sf polygon it is based on, in the shape of a horse. These are used to illustrate meshmetrics() (Section 5.3) and get_weights().

data(horse_sf, package = "stelfi")
ggplot() + geom_sf(data = mesh_2_sf(horse_mesh), fill = NA) +
    geom_sf(data = horse_sf, fill = NA, col = "red", linewidth = 1) + theme_void()
