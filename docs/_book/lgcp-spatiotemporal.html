7  Spatiotemporal LGCP

The LGCP model can also be used for spatiotemporal modelling where there is autoregressive temporal dependence.

To achieve this, we choose an arbitrary number of time knots. The equation for an AR(1) process is as follows: \[\Lambda_i(s) = \text{exp}(\beta_0 + G_i(s) + \epsilon)\] where \(i\) indexes the time knot. \(\Lambda_i(s)\) is the field intensity at time knot \(i\), and \(G_i(s)\) the GMRF at the same time knot. Each \(G_i(s)\) shares common values for \(\tau\) and \(\kappa\).

Successive random fields are correlated through the formula \[G_i(s)=\rho G_{i-1}(s) + \epsilon_i\] where \(\rho\) is a constant between -1 and +1, and \(\epsilon_i\) is normally distributed with mean 0.

7.1 An applied example: terrorism events in Iraq by year

The iraq_terrorism data (see Section 5.5 for the spatial-only analysis) also record the year of each event, so the intensity can be allowed to change from year to year. Here one time knot per year is used, so \(G_i(s)\) is the field in year \(i\) and \(\rho\) describes how strongly one year’s spatial pattern carries over into the next.

Warning

This example is a work in progress. The code has not yet been confirmed to run to completion with the current version of stelfi, so the chunks are not evaluated (eval: false). The model is sensitive to the starting values and to the time mesh, see the notes below.

7.1.1 Preparing the data

The spatial preparation is exactly as in Section 5.5 (project to UTM zone 38N, convert to km, and obtain the boundary of Iraq), but is repeated here so that this chapter can be run on its own. The only addition is the time of each event. Years are shifted so that the first year is \(t = 0\) and the time axis is then in years.

require(sf)
data("iraq_terrorism", package = "stelfi")
iraq_coordinates <- sf::st_coordinates(iraq_terrorism) |> as.data.frame()
names(iraq_coordinates) <- c("Longitude", "Latitude")
points_utm <- sf::st_as_sf(iraq_coordinates, coords = c("Longitude", "Latitude"), crs = 4326) |>
    sf::st_transform(crs = 32638)
locs_km <- as.data.frame(sf::st_coordinates(points_utm) / 1000)
names(locs_km) <- c("x", "y")
## time of each event, in years since the first year of data
year <- as.numeric(iraq_terrorism$iyear)
locs_km$t <- year - min(year)
range(locs_km$t)

iraq_sf <- rnaturalearth::ne_countries(country = "Iraq", scale = "medium",
                                       returnclass = "sf") |>
    sf::st_transform(crs = 32638) |>
    sf::st_union() |>
    sf::st_make_valid()
iraq_sf_km <- sf::st_sf(geometry = sf::st_geometry(iraq_sf) / 1000)
sf::st_crs(iraq_sf_km) <- NA

7.1.2 Space and time meshes

A spatiotemporal model has a GMRF at every time knot, so the cost is roughly the number of spatial nodes multiplied by the number of time knots. A coarser spatial mesh than in the purely spatial example is therefore used (see Section 5.1).

The time mesh has one knot per year. It is extended one knot beyond the last year of data so that the events in the final year do not sit on the very edge of the time mesh.

smesh <- fmesher::fm_mesh_2d(loc = locs_km[, 1:2],
                             boundary = fmesher::fm_as_segm(iraq_sf_km),
                             max.edge = c(100, 400), cutoff = 20)
smesh$n
## knots at 0, 1, ..., (last year + 1)
tmesh <- fmesher::fm_mesh_1d(0:(max(locs_km$t) + 1))
tmesh$loc
Note

The time knots must be on the same scale as the t column of locs. A common mistake is to give the knots only as the two end points, e.g., seq(0, 5, by = 5), which gives just two knots (0 and 5) and so a single “step” over the whole period rather than one field per year. Check tmesh$loc to see the knots that were actually created.

7.1.3 Fitting the model

Starting values are important. For the intercept the average number of events per km\(^2\) per time unit is a sensible place to start (the log intensity of a surface that is flat over both space and time). For the range of the field, which is \(\sqrt{8}/\kappa\), a starting value of 300 km is chosen, and \(\tau\) is started at a small value.

n_years <- max(locs_km$t) + 1
area_km2 <- as.numeric(sf::st_area(iraq_sf_km))
start <- c(beta = log(nrow(locs_km) / (area_km2 * n_years)),
           log_tau = log(0.1),
           log_kappa = log(sqrt(8) / 300),
           atanh_rho = 0.2)
fit <- fit_lgcp(locs = locs_km, sf = iraq_sf_km, smesh = smesh, tmesh = tmesh,
                parameters = start)
get_coefs(fit)

The coefficients are the same as the spatial model, with an additional parameter \(\rho\) (reported on the atanh scale, so \(\rho = \text{tanh}(\text{atanh\_rho})\)) that is the correlation between the fields of consecutive years. A value of \(\rho\) close to 1 means the spatial pattern of events is very persistent from year to year, whereas a value near 0 means each year’s pattern is almost unrelated to the previous one.

7.1.4 Plotting the intensity over time

The estimated intensity at a particular time knot is plotted using show_lambda() and the timestamp argument as above (the index of the time knot). Here the first and the last year of data are shown.

show_lambda(fit, smesh = smesh, sf = iraq_sf_km, tmesh = tmesh,
            timestamp = 1, clip = TRUE) +
    ggplot2::theme_void() + ggplot2::ggtitle(paste("Year", min(year)))
show_lambda(fit, smesh = smesh, sf = iraq_sf_km, tmesh = tmesh,
            timestamp = n_years, clip = TRUE) +
    ggplot2::theme_void() + ggplot2::ggtitle(paste("Year", max(year)))

If the fit does not converge, things to try are: a coarser spatial mesh, different starting values (in particular beta, log_tau, and atanh_rho), or fitting each year as a separate spatial LGCP (Chapter 5) first to get an idea of reasonable values for \(\beta_0\), \(\tau\), and \(\kappa\).

7.2 Simulating a spatiotemporal LGCP

Option 1 using sim_lgcp()

parameters <- c(beta = 1, log_tau = log(1), log_kappa = log(1), atanh_rho = 0.2)
simdata <- sim_lgcp(parameters = parameters, sf = domain, smesh = smesh, tmesh = tmesh)
simdata$x[,1] |>
    show_field(smesh = smesh) +
    ggplot2::theme_void()

Option 2 directly from the fitted model

simdata <- fit$simulate()
simdata$x[,1] |>
    show_field(smesh = smesh) +
    ggplot2::theme_void()
